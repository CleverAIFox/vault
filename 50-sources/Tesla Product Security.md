# Tesla Product Security

> 한 줄 요약: 테슬라의 취약점 신고·책임 있는 공개 정책. 지침을 지킨 선의의 보안 연구자에게는 법적 조치를 하지 않고 차량 보증도 지킨다.

## 출처
- 저자·기관: Tesla
- 날짜: 상시
- 링크: https://www.tesla.com/legal/security

## 핵심 세 줄
1. 보안 연구자와 협력해 신고된 취약점을 확인·재현·대응한다.
2. 지침을 지키면 법적 조치나 수사 의뢰를 하지 않는다.
3. 연구 등록 차량은 소프트웨어 문제가 생겨도 복구를 지원하고 보증을 무효로 하지 않는다.

## 절별 요약
- 신고 조건: 재현 정보와 개념 증명 제출, 연구 차량 밖 기능은 7일 안에 신고, 개인정보·서비스 피해 금지, 고칠 시간을 준 뒤 공개.
- 범위: 인포테인먼트·게이트웨이 바이너리, 테슬라가 만든 ECU, 에너지 제품의 보안 기능.
- 보상: 웹은 Bugcrowd, 차량·제품은 이메일로 직접 신고.

## 내 생각
- 안전이 걸린 하드웨어(차)라 연구자 보호 조항(저작권·보증)이 유난히 구체적이다. 전문가 실무(법·윤리) 관점에서 좋은 사례.
