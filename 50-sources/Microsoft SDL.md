# Microsoft SDL

> 한 줄 요약: 마이크로소프트가 20년 넘게 다듬어 온 보안 개발 생명주기(SDL). 설계부터 운영까지 열 가지 보안 실천을 정한다.

## 출처
- 저자·기관: Microsoft
- 날짜: 2004년 도입, 실천 목록은 상시 개정
- 링크: https://www.microsoft.com/en-us/securityengineering/sdl/practices

## 핵심 세 줄
1. 보안을 마지막 점검이 아니라 생명주기 전체에 넣는다.
2. 위협 모델링과 공급망 보안이 핵심 실천이다.
3. 실천 목록은 도구와 교훈이 바뀌면 함께 개정된다.

## 절별 요약
- 보안 기준·지표·거버넌스를 세운다.
- 검증된 보안 기능·언어·프레임워크를 쓴다.
- 보안 설계 리뷰와 위협 모델링을 한다.
- 암호화 기준을 정해 쓴다.
- 소프트웨어 공급망을 지킨다.
- 개발 환경을 지킨다.
- 보안 테스트를 한다.
- 운영 플랫폼 보안을 보장한다.
- 보안 감시와 대응 체계를 갖춘다.
- 보안 교육을 한다.

## 내 생각
- Maat의 GitHub 보안 기능(시크릿 스캔, Dependabot, 코드 스캔)이 5·6·7번 실천에 해당한다. 기능마다 어느 실천인지 매핑해 두면 "왜 켰는지"가 설명된다.
- 법제처 OC 키 관리가 4·6번의 실제 사례다.
