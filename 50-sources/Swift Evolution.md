# Swift Evolution

> 한 줄 요약: Swift 언어의 변경을 누구나 제안하고 공개 토론·리뷰를 거쳐 채택하는 절차. 제안서는 GitHub 저장소에 모인다.

## 출처
- 저자·기관: Swift 프로젝트(애플 주도 오픈소스), swift.org
- 날짜: 상시
- 링크: https://www.swift.org/swift-evolution/

## 핵심 세 줄
1. 누구나 아이디어를 내고 공개 포럼에서 다듬는다.
2. 다듬어진 제안이 승인되면 다음 버전의 목표로 추적된다.
3. 제안서와 절차 문서(process.md)는 GitHub swift-evolution 저장소에 있다.

## 절별 요약
- 토론: 공개 포럼에서 아이디어를 다듬는다.
- 승인: 승인된 제안은 릴리스 목표가 되어 다음 버전 기능으로 추적된다.
- 결정: 코어 팀이 주요·부차 릴리스 목표를 정한다(개별 제안 승인 주체는 절차 문서 참고, 「확인 필요」).

## 내 생각
- RFC·ADR 문화의 언어판이다. Maat 헌법을 고치는 절차(제안 → 리뷰 → 결정)를 설계할 때 본보기로 쓴다.
