# Apple Platform Security

> 한 줄 요약: 애플 하드웨어·소프트웨어·서비스에 보안이 어떻게 들어가 있는지 설명하는 공식 문서.

## 출처
- 저자·기관: Apple, Apple Support
- 날짜: 2026-08 판
- 링크: https://support.apple.com/guide/security/welcome/web

## 핵심 세 줄
1. 보안을 칩(하드웨어)부터 서비스까지 층층이 쌓는다.
2. 사용자 데이터는 암호화와 데이터 보호로 지키고, 앱은 코드 서명과 권한 통제로 묶는다.
3. 매년 개정되며 개정 이력을 공개한다.

## 절별 요약
- 하드웨어 보안: 애플 실리콘에 들어간 보안 기능.
- 시스템 보안: 부팅, 소프트웨어 업데이트, 운영체제 운영.
- 암호화와 데이터 보호: 사용자 데이터 보호, 분실 시 원격 삭제, FileVault.
- 앱 보안: 악성코드 방지, 코드 서명, 앱의 데이터 접근 통제.
- 서비스 보안: Apple 계정, iCloud, Apple Pay, iMessage 등.
- 네트워크 보안, 개발자 키트 보안, 기기 관리.

## 내 생각
- 맥북 M5로 옮긴 뒤 FileVault·보안 부팅 같은 설정을 이해하는 데 바로 쓴다.
- SWEBOK 13 보안의 "도메인별 보안" 실례다.
