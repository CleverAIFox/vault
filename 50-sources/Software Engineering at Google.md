# Software Engineering at Google

> 한 줄 요약: 구글이 수십 년 운영한 거대 코드베이스에서 얻은 문화·프로세스·도구를 정리한 책. 소프트웨어 공학을 "시간에 걸쳐 통합된 프로그래밍"으로 본다.

## 출처
- 저자·기관: Titus Winters, Tom Manshreck, Hyrum Wright 엮음, O'Reilly
- 날짜: 2020-03
- 링크: https://abseil.io/resources/swe-book

## 핵심 세 줄
1. 프로그래밍은 코드를 짜는 일, 소프트웨어 공학은 그 코드를 시간이 지나도 유지하는 일이다.
2. 시간·규모·트레이드오프가 책 전체의 세 가지 축이다.
3. 온라인에서 무료로 읽을 수 있다(CC BY-NC-ND 4.0).

## 절별 요약
- 1부 논지: 소프트웨어 공학이란 무엇인가.
- 2부 문화: 팀워크, 지식 공유, 형평성, 팀 리딩, 규모에서의 리딩, 생산성 측정.
- 3부 프로세스: 스타일 가이드, 코드 리뷰, 문서화, 테스트(개요·단위·테스트 더블·큰 테스트), 지원 중단(deprecation).
- 4부 도구: 버전 관리와 브랜치, 코드 검색, 빌드 시스템, 코드 리뷰 도구 Critique, 정적 분석, 의존성 관리, 대규모 변경, CI, CD, 서비스형 컴퓨팅.

## 내 생각
- 트렁크 기반 개발, 테스트 피라미드, 코드 리뷰 규칙 같은 볼트·Maat의 결정 대부분이 이 책에 근거를 둘 수 있다.
- 장(chapter)마다 개념 노트가 여러 개 나온다. SWEBOK 다음으로 볼트를 채울 1순위 책이다.
