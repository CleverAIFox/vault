# Spinnaker

> 한 줄 요약: 넷플릭스가 만들어 오픈소스로 공개한 멀티 클라우드 지속 전달(CD) 플랫폼. 파이프라인과 배포 전략으로 변경을 빠르고 자신 있게 내보낸다.

## 출처
- 저자·기관: 넷플릭스에서 시작(「확인 필요」), 현재 CD Foundation 프로젝트
- 날짜: 상시
- 링크: https://spinnaker.io/docs/concepts/

## 핵심 세 줄
1. 소프트웨어 변경을 빠르고 자신 있게 내보내기 위한 오픈소스 CD 플랫폼이다.
2. 애플리케이션 관리(클러스터·서버 그룹·로드 밸런서)와 배포 파이프라인 두 축이다.
3. 원하는 상태를 선언하면 실제 인프라를 맞춰 주는 관리형 전달도 지원한다.

## 절별 요약
- 애플리케이션 관리: 애플리케이션, 클러스터, 서버 그룹(배포 단위: VM·Docker 이미지), 로드 밸런서, 방화벽.
- 배포: 파이프라인(수동 또는 이벤트로 시작) → 스테이지(배포·크기 조정·수동 승인) → 태스크.
- 배포 전략: 블루/그린. 롤링 블루/그린과 카나리는 개발 중.
- 관리형 전달: test·prod 같은 환경별 원하는 상태를 선언하고 자동으로 맞춘다.

## 내 생각
- 넷플릭스 paved road의 배포 구간이다. Maat에서는 GitHub Actions + Environments(승인)가 같은 역할을 한다.
