# Tesla Software Updates

> 한 줄 요약: 테슬라 차량이 Wi-Fi로 무선(OTA) 업데이트를 받는 방식. 단계적으로 배포하고, 설치 중에는 운전할 수 없으며, 되돌릴 수 없다.

## 출처
- 저자·기관: Tesla, 고객 지원 문서
- 날짜: 상시 개정
- 링크: https://www.tesla.com/support/software-updates

## 핵심 세 줄
1. 업데이트는 Wi-Fi로 무선 배포되고 기능 추가와 개선을 함께 담는다.
2. 모든 차가 동시에 받지 않는 단계적 배포다. 개별 요청으로 먼저 받을 수 없다.
3. 설치를 시작하면 취소할 수 없고 이전 버전으로 되돌릴 수 없다.

## 절별 요약
- 다운로드: Wi-Fi 연결이 필요하며, 연결이 끊기면 멈춘다.
- 설치: 주차 상태여야 하고 설치 중에는 운전도 충전도 안 된다. 즉시·예약·야간 자동 설치를 고를 수 있다.
- 릴리스 노트: 차량 화면의 소프트웨어 탭에서 본다.
- 업데이트 선호: ADVANCED(나오는 즉시) 또는 STANDARD.

## 내 생각
- "되돌릴 수 없는 배포"라서 단계적 배포가 더 중요해지는 예시다. 메타의 단계 배포와 비교하면 좋다.
- 테슬라도 내부 공학 프로세스는 공개하지 않는다. 고객용 문서에서 운영 방식을 읽어 낸 것이라 깊이는 얕다.
